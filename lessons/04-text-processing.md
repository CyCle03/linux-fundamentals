# Step 4. 텍스트 처리와 검색

수많은 로그 파일과 설정값 속에서 원하는 것을 찾아내는 개발자의 필수 역량입니다.

## 🔍 주요 명령어

### 1. 파일 내용 보기
- `cat`: 전체 내용 출력
- `head`: 파일의 앞부분만 보기
- `tail -f`: 파일의 뒷부분을 실시간으로 추적 (서버 로그 확인 시 필수!)

### 2. `grep` (Global Regular Expression Print)
- **용도**: 특정 단어 검색
- **예시**: `grep -r "keyword" .` (현재 폴더의 모든 파일에서 특정 단어 찾기)

### 3. `|` (Pipe)
- **용도**: 명령어의 연결
- **설명**: 앞 명령어의 결과물을 뒤 명령어로 전달합니다.
- **예시**: `ls -al | grep "my_project"` (파일 목록 중 "my_project"가 포함된 것만 필터링)

### 4. `>` 와 `>>` (Redirection)
- **용도**: 결과물을 파일로 저장
- `>` : 파일 내용을 덮어쓰기
- `>>` : 파일 내용 끝에 추가하기

## 🏃 연습해보기
1. `echo "Hello Linux" > test.txt`로 파일을 만들어 보세요.
2. `cat test.txt`로 내용을 확인해 보세요.
3. `echo "Second Line" >> test.txt`로 내용을 추가해 보세요.
4. `grep "Hello" test.txt`로 검색해 보세요.
