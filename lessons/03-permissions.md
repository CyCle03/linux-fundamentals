# Step 3. 리눅스의 핵심: 권한과 소유권

리눅스에서 가장 많이 막히는 구간인 "Permission Denied" 에러를 해결하는 법을 배웁니다.

## 🔐 주요 개념 및 명령어

### 1. `ls -l` 앞부분 이해하기
`-rwxr-xr-x`와 같은 문자의 의미를 알아야 합니다.
- **r (Read)**: 읽기
- **w (Write)**: 쓰기
- **x (Execute)**: 실행

### 2. `chmod` (Change Mode)
- **용도**: 파일/폴더의 권한 수정
- **예시**: `chmod 755 [file]` (7은 소유자 모든 권한, 5는 그룹/타인 읽기 및 실행 권한)

### 3. `chown` (Change Owner)
- **용도**: 파일의 주인(소유자 및 그룹) 바꾸기
- **예시**: `chown user:group [file]`

### 4. `sudo` (Substitute User Do)
- **용도**: 루트(관리자) 권한으로 실행
- **주의**: 정말 필요할 때만 쓰세요! "나 지금 관리자 권한으로 실행할게"라는 뜻입니다.
