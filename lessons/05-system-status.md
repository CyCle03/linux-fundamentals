# Step 5. 시스템 상태 확인

리소스 관리와 프로세스 제어입니다. 내 프로그램이 잘 돌아가고 있는지 확인하는 법을 배웁니다.

## 📊 주요 명령어

### 1. `top` / `htop`
- **용도**: CPU/메모리 사용량 확인 (윈도우의 작업 관리자 역할)
- **설명**: 현재 실행 중인 프로세스들을 실시간으로 보여줍니다.

### 2. `ps -ef`
- **용도**: 현재 실행 중인 모든 프로세스 목록 보기
- **팁**: `ps -ef | grep [name]`으로 특정 프로세스만 찾아볼 때 주로 씁니다.

### 3. `kill`
- **용도**: 프로세스 종료
- **예시**: `kill -9 [PID]` (응답 없는 프로세스를 PID를 이용해 강제 종료)

### 4. `df` / `du`
- **용도**: 디스크 용량 확인
- `df -h`: 전체 디스크 용량 확인
- `du -sh`: 특정 폴더/파일의 크기 확인

---

## 🏃 연습해보기
1. `top`을 입력해 현재 시스템의 리소스 상태를 확인해 보세요 (종료는 `q`).
2. `df -h`로 디스크 여유 공간이 얼마나 남았는지 확인해 보세요.
3. `ps -ef | grep bash`로 현재 사용 중인 셸 프로세스를 찾아보세요.
